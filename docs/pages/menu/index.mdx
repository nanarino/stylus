# global

这是一个    
> 基于 CSS 变量的    
> 固执己见的    
> Microsoft Edge 优先的    
> 试作型 纯<T tag="i" data-primary="success"> [stylus](https://stylus-lang.com/) </T>套件

所有 css 变量名都是定语后置的，就像方言里把公鸡叫做鸡公，例如 `--color-button--disabled`

## install

```bash
pnpm i @nanarino/stylus
```

## import

在 css 里全局引入

```css
@import url('@nanarino/stylus')
```

或者在 js 里全局引入

```ts
import '@nanarino/stylus'
```

按需引入需要你熟悉源码（bushi🤣

比如你只是使用按钮，你需要在 stylus 代码里引入如下

```styl
// 覆写函数和定义常量
@require '@nanarino/stylus/lib/mixins/*'
// 定义 CSS 变量
@require '@nanarino/stylus/lib/variables/*'
// 设置兜底字体
@require '@nanarino/stylus/lib/common/font'
// 设置默认主题色
@require '@nanarino/stylus/lib/primary'
// 引入按钮
@require '@nanarino/stylus/lib/components/button'
```


## `data-theme`

主题变量 `theme: 'light'|'dark'`    
它保存在 `document.documentElement.dataset` 和 `localStorage` 里

使用本文档右上角可以快捷切换主题


## color

全局变量

- 纯黑 `--black` 
- 纯白 `--white`
- 色相 `--hue-{name}`
- 色度 `--chroma-{level}`
- 明度 `--lightness-{level}`

其中 level ∈ `[1, 10]`， name ∈ &#123; {['primary', 'success', 'danger', 'warning', ...colors].map(primary =>
    <><T tag='code' class='☘-code ☘-font-mono' style={`--background-color-code:var(--${primary}-2)`}>{primary}</T>, </>
)}&#125;

前四种为功能主题色，后面为预设色卡：

### `data-primary`

`[data-primary]` 可以修改子元素所继承的功能主题色。

<T tag="ul" class="☘-list">
{
    ['', 'success', 'danger', 'warning'].map(primary => 
        <li data-primary={primary}>
            <T tag='code' class='☘-code ☘-font-mono'>[data-primary{primary && `=${primary}`}]</T>
        </li>
    )
}
</T>

需要 `[data-primary]` 才可以额外获得主题色的组件往往具有局部变量，如 `button` 的 `--color-button`    
不需要 `[data-primary]` 就具备主题色的组件往往具有全局变量，如 `tag` 的 `--color-tag`

#### **自订主题**

非常容易，比如设置主题色为蓝色，只需要： <T tag='span' data-primary style='--hue-primary: var(--hue-blue)'>`--hue-primary: var(--hue-blue)`</T>，就赋予了预设色卡中蓝色行的色相

也可以是任意数值的色相和灰阶

## message

往 `body>.☘-message-queue` 里 append 以下元素即可显示消息

- `--background-color-message` 局部变量 改变消息背景色 OKLCH 通道

```pug
.☘-message(data-primary style={
    "--background-color-message": 'var(--magenta-5)',
    "--box-shadow-color": 'var(--magenta-4)'
})
    p.☘-paragraph
        svg.☘-message-prefix
        span 发射成功
```

对于本文档页面的消息使用的是：添加元素后再定期移除。

<EmitMessage />


## `z-index`

| className                     | z-index | 用于    |
| ----------------------------- | ------- | ------ |
| `.☘-table-header-group`       | 10      | 表头/尾 |
| `.☘-popover\|dialog`          | 100     | 气泡弹框 |
| `.☘-layout-aside[data-float]` | 1000    | 悬浮菜单 |
| `.☘-message-queue`            | 10000   | 消息弹框 |
